# ميزات متقدمة وتحليلات شاملة (Manarah v2+)

## 1) محرك تخصيص ذكي
- توصية شرارات حسب اهتمامات وسلوك المستخدم.
- ترتيب feed باستخدام score يجمع: الصلة + الحداثة + مستوى الصعوبة.

## 2) Cohort Analytics
- تقسيم المستخدمين حسب تاريخ التسجيل، القناة، والمستوى.
- قياس retention: D1 / D7 / D30.

## 3) Funnel كامل
- زيارة → تسجيل → أول شرارة → إكمال → مشاركة.
- مقارنة التحويل حسب المصدر (يوتيوب/إكس/لينكدإن).

## 4) Partner Intelligence
- تقرير لكل شريك:
  - أكثر محتوى يطلق شرارات مكتملة.
  - متوسط زمن الإكمال.
  - تأثير المحتوى على العودة الأسبوعية.

## 5) A/B Testing
- اختبار صيغ العناوين وزر CTA.
- اختبار طول الشرارة (قصير/متوسط/مفصل).

## 6) Embedded Widget SDK
- JavaScript snippet بسيط للتضمين في أي موقع:
```html
<script async src="https://cdn.manarah.ai/widget.js" data-partner="allam" data-theme="dark"></script>
```
- يفتح Mini-panel فيه أحدث الشرارات مع تتبع UTM.

## 7) Enterprise Readiness
- RBAC للصلاحيات.
- Audit log.
- SLA monitoring + alerting.
