# كيف أتصفح المنصة؟

## 1) المعاينة السريعة (بدون Backend)
1. من جذر المشروع شغّل:
   ```bash
   python3 -m http.server 8080
   ```
2. افتح المتصفح على:
   `http://localhost:8080/web/index.html`

> هذه المعاينة تعرض الواجهة والتفاعل الأساسي فقط.

## 2) تشغيل API الحقيقي (`/api/spark`)
للحصول على توليد شرارات فعلي، شغّل المشروع داخل Next.js أو Vercel لأن الملف `api/spark.js` هو Serverless Function.

### المتطلبات
- متغير بيئة: `ANTHROPIC_API_KEY`
- Endpoint متاح: `/api/spark`

## 3) ما الذي ستراه داخل المنصة؟
- شريط أخبار حي (Ticker)
- نموذج توليد شرارة
- قائمة آخر الشرارات
- واجهة متجاوبة للهاتف

## 4) خطوات التصفح المقترحة للمستخدم
1. اكتب محتوى (من يوتيوب/منشور اجتماعي/مقال).
2. اختر مستوى التعلم.
3. اضغط "أشعل الشرارة".
4. شارك الناتج لاحقًا عبر رابط مخصص (ضمن المرحلة 3).
